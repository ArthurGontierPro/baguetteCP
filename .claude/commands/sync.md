Orient before doing anything else.

1. `git log --oneline -20` and `git status` — what has landed, and is the tree clean?
2. Read `## Active claims` in `WORKLOG.md`: what is being worked on right now, and which
   files are therefore off limits to you.
3. Read the last three entries under `## Handoff notes`.
4. Check `## Cross-session requests` for anything addressed to a file you own.
5. Skim `docs/DECISIONS.md` for entries newer than the ones you already know about,
   especially any that moved from `OPEN` to `DECIDED`.
6. Report back in a few lines: what changed, what is claimed, what is free to pick up
   from `docs/ROADMAP.md`, and whether anything conflicts with what I asked you to do.
